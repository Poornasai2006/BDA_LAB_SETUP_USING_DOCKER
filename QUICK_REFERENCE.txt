QUICK START (WHEN RECREATING):
================================================================================

1. Prepare workspace with binaries:
   mkdir workspace
   # Place 3 files above in workspace/

2. Build the custom image:
   docker build -t local/hadoop-namenode-sqoop:2.7.4 .

3. Start all services:
   docker-compose up -d

4. Wait 1-2 minutes, then verify:
   docker-compose ps

5. Access services:
   NameNode UI:        http://localhost:50070
   YARN UI:            http://localhost:8088
   History Server:     http://localhost:8188
   HiveServer2:        localhost:10000
   MySQL:              localhost:3307 (root/root)

COMMON COMMANDS:
================================================================================

MANAGEMENT:
  docker-compose up -d          # Start all containers
  docker-compose down           # Stop containers (keep data)
  docker-compose down -v        # Stop and remove volumes
  docker-compose ps             # Check status
  docker-compose logs -f        # View live logs

FILE OPERATIONS:
  docker cp file.txt namenode:/tmp/           # Copy TO container
  docker exec namenode hadoop fs -put /tmp/file.txt /   # Put in HDFS
  docker exec namenode hadoop fs -ls /        # List HDFS
  docker exec namenode hadoop fs -cat /file   # Read HDFS file

MAPREDUCE:
  docker exec namenode hadoop jar /tmp/job.jar jobclass /input /output
  
HIVE:
  docker exec -it hive-server hive             # Enter Hive shell (CORRECT WAY)
  
PIG:
  docker exec -it namenode pig                 # Enter Pig shell
  docker exec namenode pig -f /tmp/script.pig  # Run Pig script
  
SQOOP IMPORT:
  docker exec namenode sqoop import \
    --connect jdbc:mysql://mysql-db:3306/testdb \
    --username root --password root \
    --table tablename -m 1 \
    --target-dir /sqoop_import/tablename

MYSQL:
  docker exec mysql-db mysql -u root -proot -e "SHOW DATABASES;"

================================================================================
VOLUMES & DATA PERSISTENCE:
================================================================================

Named Volumes (Docker managed):
  namenode              → /hadoop/dfs/name
  datanode              → /hadoop/dfs/data
  hadoop_historyserver  → /hadoop/yarn/timeline

Local Mount:
  ./workspace           → /workspace (in all containers)

Data Persists After:
  docker-compose stop   ✅ (volume remains)
  docker-compose down   ✅ (volume remains)
  docker-compose down -v ❌ (volume deleted)

Recovery:
  Data in named volumes is permanent until -v flag used
  Always backup workspace/ separately

================================================================================
TROUBLESHOOTING:
================================================================================

Containers won't start?
  docker-compose logs [service-name]

Out of memory?
  Increase Docker resources in Docker Desktop settings
  OR edit hadoop-hive.env: YARN_CONF_yarn_nodemanager_resource_memory___mb

Port conflicts?
  Use: netstat -ano | findstr :PORT
  Change ports in docker-compose.yml

Services taking too long?
  Normal startup: 1-2 minutes
  Check: docker-compose ps
  View logs: docker-compose logs -f

Can't connect to MySQL?
  docker exec mysql-db mysql -u root -proot -e "SELECT 1;"

Hive metastore issues?
  Restart: docker-compose restart hive-metastore
  Wait a moment, then retry
